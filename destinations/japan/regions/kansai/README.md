# Kansai

Japan's cultural and historical heart: Kyoto (imperial capital), Osaka (food and neon), Nara (deer park and Todai-ji), Kobe (port, beef). Everything is within 30–75 min by train — ideal for multi-city stays.

## What defines this region

- Kyoto: temples, shrines, geisha districts, preserved Higashiyama lanes.
- Osaka: food capital, Dotonbori neon, castles, day-trip hub.
- Nara: Todai-ji's Great Buddha, free-roaming deer, old capital.
- Kobe: port city, night view from Mount Rokko, wagyu beef.
- Transport: JR + Hankyu + Kintetsu + Keihan networks; IC card (ICOCA) everywhere.
