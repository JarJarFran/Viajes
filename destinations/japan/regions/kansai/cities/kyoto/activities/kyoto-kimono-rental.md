# Kimono/yukata rental & photo walk

## Description

Rent a kimono/yukata and walk Higashiyama/Gion in style; many shops include hair styling and photo spots.

## How to get there

Rental shops cluster around Kiyomizu-dera, Gion, Kyoto Station (e.g. Okamoto, Yae).

## Tips

Book online. Winter: wear heattech underneath. Return by closing time.
