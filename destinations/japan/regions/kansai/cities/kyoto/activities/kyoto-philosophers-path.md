# Philosopher's Path (Tetsugaku-no-michi)

## Description

2 km canal-side stone path between Ginkaku-ji and Nanzen-ji, lined with cherry trees; cafes and small shrines along the way.

## How to get there

Eiden Ginkakuji-michi Station, walk south; or bus to Ginkakuji-michi.

## Tips

Quiet early morning. Combine: Ginkaku-ji → path → Nanzen-ji in one walk.
