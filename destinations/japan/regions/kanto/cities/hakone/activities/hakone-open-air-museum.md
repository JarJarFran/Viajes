# Hakone Open-Air Museum

## Description

Japan's first open-air art museum, with sculptures set in a hillside park and an indoor Picasso Pavilion.

## How to get there

Next to Chokoku-no-Mori Station on the Hakone Tozan Railway (one stop before Gora).

## Tips

Older guides list ¥1,600; the official current window price is ¥2,000 — buy the web ticket to pay ¥1,800.
