# Shibuya Sky (observation deck)

## Description

Shibuya's newest observatory: 229 m, rooftop helipad, 360° views (Mt Fuji on clear days).

## How to get there

JR/Metro/Keio/... Shibuya Station, Shibuya Scramble Square.
