# Sumida River cruise (Asakusa → Odaiba, Himiko)

## Description

Futuristic Himiko/Water Bus along the Sumida river: Asakusa → Hamarikyu → Odaiba under 12 bridges.

## How to get there

Asakusa pier (next to Senso-ji) or Hamarikyu pier.

## Tips

Nice way to link Asakusa with Odaiba. Check timetable — not all courses run all day.
