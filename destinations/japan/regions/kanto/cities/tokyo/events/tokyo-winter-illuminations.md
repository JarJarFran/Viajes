# Tokyo winter illuminations (January)

## Description

City-wide winter light season. Still active in January: Marunouchi Illumination (Gyoko-dori, to ~Feb 14), Shinjuku Southern Terrace (to ~Feb 14), Shinjuku Chuo Park (to ~Jan 12), Caretta Shiodome (Shiodome), Roppongi Hills Keyakizaka, Yomiuriland Jewellumination (selected days, from ¥1,800).

## How to get there

Various: Marunouchi = Tokyo Station; Shinjuku = Shinjuku Station south exit; Caretta = Shimbashi; Roppongi = Roppongi Station.

## Tips

Easy evening activity any night in winter. Yomiuriland needs advance tickets and is ~40 min from Shinjuku.
