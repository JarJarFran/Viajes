# Matsumoto Castle

## Description

Black-walled castle whose keep is one of Japan's twelve original castle keeps, with steep wooden stairs inside. It is the city's main sight.

## Tips

Buy the e-ticket online to save ¥100. Seismic reinforcement work was scheduled to start later in 2026, so check whether the keep interior is affected.
