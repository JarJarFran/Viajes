# Zuihoden Mausoleum

## Description

Mausoleum (otamaya) of Date Masamune, founder of the Sendai domain. Run by the Zuihoden foundation as the main Date-clan heritage site in the city.

## How to get there

Loople Sendai bus to 'Zuihoden-mae', the 4th stop from Sendai Station; the loop is one-way, so return by regular bus or continue on the loop.

## Tips

Official site lists ¥570 for adults; some third-party listings still show an older ¥550. Show a Loople 1-day pass for the ¥460 rate.
